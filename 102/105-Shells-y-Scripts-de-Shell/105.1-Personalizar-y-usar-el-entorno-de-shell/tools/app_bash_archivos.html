2 · Laboratorio en vivo: PS1 y alias

Prompt PS1: prueba secuencias \u \h \W \w \$ \t \d.

murci@lpic:~$ _

Alias y funciones: el alias abrevia; la función admite parámetros.

Sin alias. Prueba con ll, gs, ..

Recuerda: alias ll='ls -l' vive en ~/.bashrc; export PATH=$PATH:~/bin en el perfil login; source ~/.bashrc recarga sin salir. env lista exportadas, set todas, unset VAR borra.

3 · Variables: PATH, EDITOR y Skeleton

Escribe una variable y expórtala (simulado):

=
export EDITOR=vim …

Ficheros modelo para usuarios nuevos en /etc/skel/: al crear con useradd -m se copian .bashrc, .profile y .bash_logout de serie.

Orden de personalización recomendado: PATH y locales en perfil; alias, prompt y funciones en ~/.bashrc.
