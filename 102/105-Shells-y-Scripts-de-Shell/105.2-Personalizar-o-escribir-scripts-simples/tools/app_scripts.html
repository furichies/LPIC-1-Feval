2 · Chuleta exprés: $? y encadenados

$? guarda la salida del último comando (0 = éxito). cmd1 && cmd2 ejecuta cmd2 solo si cmd1 triunfa; cmd1 || cmd2 solo si falla.

./script.sh → echo $? …
TestSignificado
[ -f f ]f es fichero regular
[ -d d ]d es directorio
[ -n "$v" ]v no vacía
[ "$a" = "$b" ]cadenas iguales
[ "$n" -gt 10 ]comparación numérica

Argumentos: $0 nombre, $1 $2… parámetros, $# nº, $@ todos. Cita siempre: "$var".

3 · Permisos y ejecución

Un script necesita lectura + ejecución. Formas de lanzarlo:

OrdenRequiere +xNota
./script.shsíusa su shebang
bash script.shnofuerza intérprete
source script.shnocorre en la shell actual

Debug: bash -x script.sh traza cada línea. bash -n script.sh solo chequea sintaxis sin ejecutar.

Redacción propia con fines didácticos. Comprueba en tu distro con ls -l y chmod +x.
