# 110.3 Cifrado de datos

- Examen: 102-500 · Tema: Tema 110: Seguridad · Peso (importancia): **4**
- Fuente canónica (no se copia, solo se referencia): https://learning.lpi.org/es/learning-materials/102-500/ y https://www.lpi.org/es/exam-101-102-objectives/

## Áreas de conocimiento (objetivo oficial, resumen propio)
OpenSSH2 cliente; host keys; GnuPG (incl. revocar); cifrar/firmar/verificar; túneles SSH+X11

## Ficheros / comandos del objetivo
`ssh ssh-keygen ssh-agent ssh-add ~/.ssh/id_* /etc/ssh/ssh_host_* ~/.ssh/authorized_keys ssh_known_hosts gpg gpg-agent ~/.gnupg`
