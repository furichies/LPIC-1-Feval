109.4 Configurar DNS del lado del cliente Peso 2 · v5.0

Objetivo: orden en /etc/nsswitch.conf (files/dns), /etc/hosts, /etc/resolv.conf y dig/host/getent.

1 · Ordena nsswitch: ¿files o dns primero?

El orden decide quién puede suplantar a quién:

Destino

hosts: files dns …
Con files dns, una línea en /etc/hosts gana al DNS: útil para pruebas y peligroso si se olvida (típica pregunta trampa).

2 · resolv.conf + herramientas

Pulsa…

3 · Ejemplo completo

/etc/nsswitch.conf: hosts: files dns networks: files dns /etc/hosts: 127.0.0.1 localhost 192.168.1.50 mi-servidor impresora /etc/resolv.conf: search ejemplo.com nameserver 1.1.1.1 nameserver 8.8.8.8

search completa nombres cortos; nameserver máximo 3. Si lo gestiona NetworkManager o systemd-resolved, no lo edites a mano (mira resolvectl status).
