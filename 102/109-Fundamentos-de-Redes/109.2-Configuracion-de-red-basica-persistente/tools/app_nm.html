1 · Constructor nmcli

Completa los campos y genera la secuencia add → mod → up lista para copiar.

Pulsa «Generar comandos»…

Recuerda: add crea, mod ajusta y up aplica. Sin el up final, el cambio queda guardado pero inactivo.

Comprueba siempre con ip -brief addr después de activar: la IP debe aparecer junto a tu interfaz.

3 · Wi-Fi, hostname y comprobación

Despliega cada bloque: lo que falta para redondear la red persistente.

Conectar a una Wi-Fi con nmcli

Ver redes: nmcli dev wifi list.

Conectar: nmcli dev wifi connect "Casa" password "clave123".

La conexión queda guardada y se reconecta sola al arrancar.

Ver guardadas: nmcli con show.

Borrar una: nmcli con delete "Casa".

Activar, cortar y preguntar estado

nmcli con up "casa" activa la conexión.

nmcli con down "casa" la desactiva sin borrarla.

nmcli dev status resume dispositivos y estado.

nmcli -p con show "casa" detalla IP, DNS y rutas.

Nombre del equipo (hostname)

Ver: hostnamectl o cat /etc/hostname.

Fijar: hostnamectl set-hostname taller1.

Es persistente: sobrevive al reinicio.

Añade el nombre a /etc/hosts para resolución local:

127.0.1.1 taller1

Comprobación final de tu red

ip -brief addr → ¿tengo IP en la interfaz?

ip route | grep default → ¿hay puerta de enlace?

cat /etc/resolv.conf → ¿hay nameserver?

ping -c2 1.1.1.1 → ¿salgo a internet por IP?

getent hosts ejemplo.es → ¿resuelvo nombres?

Si los cinco pasan, tu configuración persistente es correcta.
