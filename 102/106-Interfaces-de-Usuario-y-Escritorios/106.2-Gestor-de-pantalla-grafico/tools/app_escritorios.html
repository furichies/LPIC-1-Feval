3 · Gestor de pantalla y Wayland frente a Xorg

El gestor de pantalla (display manager) es el login gráfico: lanza el servidor gráfico y abre tu sesión de escritorio.

GDM (GNOME Display Manager) — el de GNOME

Es el gestor por defecto en Debian, Ubuntu, Fedora y RHEL con GNOME.

Servicio systemd: systemctl status gdm.

Config básica en /etc/gdm3/custom.conf (p. ej. WaylandEnable=false para forzar Xorg).

Comando típico: systemctl set-default graphical.target para arrancar siempre en modo gráfico.

SDDM — el de KDE Plasma

Ligero, basado en QML y temas visuales. El habitual con Plasma.

Servicio systemd: systemctl status sddm.

Config en /etc/sddm.conf o /etc/sddm.conf.d/.

Ahí se fija el tema, el usuario por defecto y la sesión inicial.

LightDM — ligero y multi-escritorio

El clásico de Xfce, LXDE y equipos modestos. Muy configurable.

Servicio systemd: systemctl status lightdm.

Config en /etc/lightdm/lightdm.conf.

Permite invitados, autologin y varios greeters (pantallas de login).

Wayland frente a Xorg (X11)

Xorg es el servidor gráfico clásico: maduro, compatible con red (X forwarding por SSH) y con XDMCP.

Wayland es el sustituto moderno: más seguro y fluido, pero el reenvío gráfico por red funciona distinto (p. ej. con RDP/VNC del propio compositor).

Comprueba tu sesión con: echo $XDG_SESSION_TYPE (responde wayland o x11).

Truco de examen: si algo gráfico remoto falla en Wayland, prueba sesión Xorg antes de tocar la red.

Arranque gráfico o texto

systemctl get-default muestra el objetivo actual.

graphical.target = con gestor de pantalla.

multi-user.target = solo consola de texto.

Cámbialo con systemctl set-default según necesites.
