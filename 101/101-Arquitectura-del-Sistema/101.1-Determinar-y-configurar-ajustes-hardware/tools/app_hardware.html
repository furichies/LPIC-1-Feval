Cada herramienta consulta el kernel o el bus correspondiente.

  • lspci -k muestra el módulo del kernel asociado a cada PCI.
  • lsusb -t dibuja el árbol de buses y puertos USB.
  • modinfo btusb describe un módulo antes de cargarlo.
