Arrancar el sistema

Fases del arranque, journalctl y dmesg. Redacción propia con fines didácticos.

1 Línea temporal del arranque (clicable)

Pulsa cada fase para ver qué hace, qué ficheros toca y qué comando la inspecciona.

Pulsa una fase para ver su detalle…
  • Orden que debes memorizar: firmware → gestor → kernel → initramfs → /sbin/init (systemd).
  • UEFI usa partición ESP (FAT32, /boot/efi).
  • BIOS usa MBR + código en los primeros 446 bytes.
  • El kernel monta el initramfs para cargar drivers de disco, cifrado o LVM.
  • systemd es el PID 1 y alcanza el default.target.
Para el examen: asocia cada error a su fase. «grub rescue>» = fase 2 · «kernel panic» = fase 3 · «initramfs>» = fase 4 · «failed to start …service» = fase 5.

2 Simulador journalctl / dmesg con filtros

Elige fuente y nivel, y escribe un texto para filtrar (ej: error, usb, grub).

Comandos reales: journalctl -b -p err · dmesg | grep -i usb · journalctl -u sshd --since today.

dmesg = anillo del kernel · journalctl -b = registro del arranque actual persistido por systemd-journald.
