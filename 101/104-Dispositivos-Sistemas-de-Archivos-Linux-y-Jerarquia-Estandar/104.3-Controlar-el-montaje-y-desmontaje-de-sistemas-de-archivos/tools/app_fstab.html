2 · blkid, UUID y mount

Usa blkid para ver UUIDs estables (no cambian como /dev/sdb1). findmnt y df -hT verifican el montaje.

$ blkid
/dev/sdb1: UUID="4a5b-9c2e" TYPE="ext4"
/dev/sdc1: UUID="AA11-BB22" TYPE="vfat"
$ mount | grep datos
/dev/sdb1 on /datos type ext4 (rw,relatime)
$ findmnt /datos   → confirma punto y opciones
